# Текст на странице

Адрес приложения после включения GitHub Pages: **https://seililinka.github.io/HTMLka/**.
Выберите HTML-файл, измените текст или данные графиков и скачайте исправленную страницу.


Редактор текста и данных графиков в готовом HTML. Пользователь видит страницу и поля правки, без исходного кода.

## Запуск на GitHub Pages

Сборка и публикация настроены в `.github/workflows/pages.yml`. В репозитории откройте **Settings → Pages → Source → GitHub Actions**. Затем запустите workflow **GitHub Pages** через **Actions → Run workflow** либо повторите его последний запуск. После включения Pages новые изменения в `main` публикуются автоматически.

Для приватного репозитория нужен GitHub Pro или другой тариф с поддержкой приватных репозиториев в Pages. На GitHub Free репозиторий должен быть публичным; видимость кода меняется отдельно владельцем.

В браузере работают импорт HTML, текст, данные графиков, связи с числами, отмена и скачивание. Файлы обрабатываются на устройстве. GitHub Pages обслуживает статические файлы, поэтому вкладка ИИ в этой версии скрыта; серверный запуск ниже сохраняет её. Ключи API не нужны для Pages и не включаются в сборку.

Проверить эту сборку локально: `npm ci && npm run build:pages`. Готовые файлы находятся в `dist-pages/`.

## Счётчик открытий

На опубликованной странице под документом показан общий счётчик [Hits.sh](https://github.com/silentsoft/hits). Учёт начат 10 октября 2026 года. Он считает загрузки значка при открытии приложения, включая повторные открытия и технические проверки; это не число уникальных посетителей. Перерисовка при правке текста, графиков и открытии HTML сохраняет тот же элемент изображения и не создаёт новый запрос. История до подключения счётчика не восстанавливается. Блокировщики и недоступность сервиса могут приводить к пропускам, а публичный счётчик не защищён от накрутки.

Счётчик включён только в сборке Pages на `https://seililinka.github.io/HTMLka/` (также `/HTMLka/index.html` и `/HTMLka`). В разработке, тестах и других размещениях он отключён. Адрес запроса фиксирован; содержимое файла, его название, выбранный текст, параметры адреса страницы и её referrer не передаются. Сервис получает обычный сетевой запрос, включая IP-адрес. Редактор не добавляет cookies, идентификаторы пользователя или локальное хранилище для учёта. Число и статистика по дням публичны. Счётчик расположен вне импортированного HTML и не попадает в скачиваемый файл. При ошибке загрузки показывается «Счётчик недоступен», остальные функции продолжают работать.

## Что работает

- Открытие `.html` / `.htm` с локального устройства, до 10 МБ.
- Правка выбранного текста на странице или в панели; отмена и повтор действий.
- Значения и подписи графиков; автоматические и ручные связи с числами в тексте.
- Скачивание исправленного HTML с сохранением исходных тегов, оформления, ссылок и скриптов. Ручные связи сохраняются при повторном открытии.
- Предложения ИИ с явным применением пользователем, когда настроен серверный AI API.

Импортированный HTML не отправляется на сервер. При запросе к ИИ передаются выбранный фрагмент, задача и тип текста. Во время редактирования скрипты импортированного файла отключены; в скачанном исходнике они сохраняются.

## Быстрый запуск

Нужны Node.js 24 или новее и npm.

```sh
npm ci
npm run dev
```

Откройте **http://127.0.0.1:3000**. Сразу доступен пример отчёта с графиком. Для своего документа нажмите «Открыть HTML», выберите текст или вкладку «Графики», внесите правки и нажмите «Скачать».

Для собранной версии:

```sh
npm run build
npm start
```

## ИИ

Ручное редактирование и графики работают без ключей. В исходной версии ИИ обслуживался встроенным сервисом Floot; он не переносится в отдельный репозиторий. Здесь добавлен серверный адаптер для сервиса с OpenAI Chat Completions API и JSON Schema.

Создайте `.env` по образцу `.env.example` и задайте `AI_API_KEY`, `AI_MODEL`, а при необходимости `AI_API_BASE_URL`. Выберите модель вашего сервиса, поддерживающую `response_format: json_schema`. После настройки перезапустите сервер. Без настройки приложение сообщает, что ИИ ещё не подключён; остальные функции доступны.

Ключ хранится только на сервере. `.env` исключён из Git. Клиентская сборка ключа не содержит. Сервер по умолчанию слушает только локальный адрес. Для HTTPS через обратный прокси задайте `APP_ORIGIN` равным адресу приложения; доступ и оплату AI API настройте у своего хостинга.

## Графики

| Формат | Поведение |
| --- | --- |
| CSS-столбики / индикаторы с шириной или высотой в `%` / `px` | Изменяются числа и размеры элементов. |
| Chart.js, ECharts, Plotly со статическими массивами в HTML | Конфигурации разбираются без запуска JS; данные изменяются в исходнике, в редакторе показывается SVG. |
| Распознаваемые SVG-столбики | График перестраивается по отредактированным данным. |
| Неизвестный canvas, SVG или картинка графика | Пользователь вводит реальные данные и строит диаграмму выбранного типа. |

Серверные, загружаемые по сети и вычисляемые во время выполнения JS данные автоматически не распознаются. Одинаковые числа в разных местах не заменяются глобально; связь можно выбрать вручную в поле «График для этого числа».

## Устройство проекта

`pages/_index.tsx` — интерфейс; `helpers/HtmlTextDocument.tsx` — текст и история; `helpers/HtmlCharts.tsx` — распознавание и связи; `helpers/renderEditableChart.tsx` — SVG; `components/ChartEditor.tsx` — ввод данных; `endpoints/rewrite_POST.ts` — серверный AI адаптер; `server.ts` — разработка и запуск сборки.

Версия перенесена из проекта Floot «Текст на странице», исходная ревизия **1791533429037**. При подготовке исправлена перерисовка графика после отмены / повтора; исправление внесено и в Floot. Обработчик со встроенным Floot AI сохранён в `floot-original/` для сравнения и восстановления.

Документация инструментов: [Vite](https://vite.dev/guide/), [Chat Completions API](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create).
