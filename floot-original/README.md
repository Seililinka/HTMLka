# Исходный обработчик Floot

`rewrite_POST.ts` — исходная версия обработчика из Floot, использующая встроенный `@floot/ai`. Сохранена для восстановления и сравнения; самостоятельная сборка её не включает.

В рабочем `endpoints/rewrite_POST.ts` тот же контракт запроса и ответа реализован через настраиваемый серверный AI API. Никакие ключи или токены предпросмотра Floot в этот проект не переносились.
